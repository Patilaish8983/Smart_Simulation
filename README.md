# Smart_Simulation

This is live demo link of how the project works : https://patilaish8983.github.io/Smart_Simulation/
This is an idea faced  daily , while  purchasing furniture for the house, we cannot imagine which colour , size will fit in which area , so this  idea helps the person to simulate in real in any room of the house through live camera and take decisions hassle-free.


## 🛠️ Technical Architecture & Stack
*   **Frontend Interface:** Semantic HTML5, CSS3 Glassmorphic UI System
*   **Graphics & Simulation Engine:** HTML5 Canvas API (Object Reference Model Architecture)
*   **Camera Pipeline Stream:** WebRTC MediaDevices API
*   **Core Logic Language:** Vanilla JavaScript (ES6+)
*   **Algorithms Applied:** 2D Bounding-Box Intersections, Vector-based Mouse Coordinate Delta Mapping, Frame Boundary Clamping Contraints.
